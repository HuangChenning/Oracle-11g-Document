## New Features in SQL\*Plus Release 11.2

SQL\*Plus Release 11.2.0.2 is a superset of SQL\*Plus 11.2. This section describes new features introduced in SQL\*Plus Release 11.2.0.2.

- SET XMLOPTIMIZATIONCHECK
	A new SET command specifies that only fully optimized XML queries and DML operations are executed. It is only to assist in developing and debugging, not for production.
