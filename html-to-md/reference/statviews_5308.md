`USER_FILE_GROUP_VERSIONS` shows top-level version information for all file groups owned by the current user. Its columns (except for `FILE_GROUP_OWNER`) are the same as those in ["ALL\_FILE\_GROUP\_VERSIONS"](statviews_1097.md).
