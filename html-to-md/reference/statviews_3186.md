`DBA_FILE_GROUP_TABLESPACES` shows information about the transportable tablespaces present (partially or completely) in all file sets in the database (when the file set contains dump files). Its columns are the same as those in ["ALL\_FILE\_GROUP\_TABLESPACES"](statviews_1096.md).
