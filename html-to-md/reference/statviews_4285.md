`DBA_SQLSET_REFERENCES` describes whether or not all SQL tuning sets in the database are active. A SQL tuning set cannot be dropped if it is referenced. Its columns are the same as those in ["ALL\_SQLSET\_REFERENCES"](statviews_2073.md).
