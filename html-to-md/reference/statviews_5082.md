`DBA_USERS_WITH_DEFPWD` displays all users in the database that are still using their default passwords.

| Column | Datatype | NULL | Description |
| --- | --- | --- | --- |
| `USERNAME` | `VARCHAR2(30)` | `NOT NULL` | Name of the user |
