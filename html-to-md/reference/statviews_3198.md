`DBA_GOLDENGATE_INBOUND` displays information about all GoldenGate inbound servers in the database. Its columns are the same as those in `ALL_GOLDENGATE_INBOUND`.

Note:

This view is available starting with Oracle Database 11g Release 2 (11.2.0.4).
