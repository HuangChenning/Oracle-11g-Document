`USER_FILE_GROUP_EXPORT_INFO` shows export-related information for all file groups that the current user can manage. Its columns (except for `FILE_GROUP_OWNER`) are the same as those in ["ALL\_FILE\_GROUP\_EXPORT\_INFO"](statviews_1093.md).
