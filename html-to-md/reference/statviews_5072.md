`DBA_TSTZ_TABLES` displays information about all tables in the database, which have columns defined on `TIMESTAMP WITH TIME ZONE` data types or object types containing attributes of `TIMESTAMP WITH TIME ZONE` data types. Its columns are the same as those in `ALL_TSTZ_TABLES`.
