`USER_IND_PARTITIONS` describes, for each index partition owned by the current user, the partition-level partitioning information, the storage parameters for the partition, and various partition statistics generated by the `DBMS_STATS` package. Its columns are the same as those in ["ALL\_IND\_PARTITIONS"](statviews_1105.md).
