`DBA_FILE_GROUP_EXPORT_INFO` shows export-related information for each version in the database that has a valid Data Pump dump file. Its columns are the same as those in ["ALL\_FILE\_GROUP\_EXPORT\_INFO"](statviews_1093.md).
