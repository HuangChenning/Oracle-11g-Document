| Property | Description |
| --- | --- |
| Parameter type | Integer |
| Default value | `4` |
| Modifiable | `ALTER SYSTEM` |
| Range of values | `1` to `30` |
| Basic | No |

`LOG_ARCHIVE_MAX_PROCESSES` specifies the maximum number of ARCn processes that can be created.
