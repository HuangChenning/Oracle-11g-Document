The scripts in Table B-5 are useful only if the JServer option is installed.

Table B-5 Java Scripts

| Script Name | Description |
| --- | --- |
| `initjvm.sql` | Initializes JServer by installing core Java class libraries and Oracle-specific Java classes |
| `rmjvm.sql` | Removes all elements of the JServer |
| `catjava.sql` | Installs Java-related packages and classes |
