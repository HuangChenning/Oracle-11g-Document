`USER_TAB_SUBPARTITIONS` describes, for each table subpartition owned by the current user, the subpartition name, name of the table and partition to which it belongs, and its storage attributes. Its columns are the same as those in ["ALL\_TAB\_SUBPARTITIONS"](statviews_2116.md).

Note:

Statistics are not collected on a per-subpartition basis.
