## B Automatic and Manual Locking Mechanisms During SQL Operations

This appendix describes mechanisms that lock data either automatically or as specified by the user during SQL statements. For a general discussion of locking mechanisms in the context of data concurrency and consistency, see [Oracle Database Concepts](https://docs.oracle.com/cd/E11882_01/server.112/e40540/consist.htm#CNCPT1313).

This appendix contains the following sections:

- [Automatic Locks in DML Operations](ap_locks001.md)
- [Automatic Locks in DDL Operations](ap_locks002.md)
- [Manual Data Locking](ap_locks003.md)
