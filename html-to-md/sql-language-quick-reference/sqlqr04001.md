A condition specifies a combination of one or more expressions and logical (Boolean) operators and returns a value of `TRUE`, `FALSE`, or unknown.

Conditions have several forms. The sections that follow show the syntax for each form of condition. Refer to [Chapter 5, "Subclauses"](sqlqr05.md) for the syntax of the subclauses.

See Also:

[Conditions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions.htm#SQLRF005) in [Oracle Database SQL Language Reference](https://docs.oracle.com/cd/E11882_01/server.112/e41084/toc.htm) for detailed information about SQL conditions

[BETWEEN condition](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions011.htm#SQLRF52164)

```
expr1 [ NOT ] BETWEEN expr2 AND expr3
```

[Compound conditions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions010.htm#SQLRF52162)

```
{ (condition)
| NOT condition
| condition { AND | OR } condition
}
```

[EQUALS\_PATH condition](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions009.htm#SQLRF52155)

```
EQUALS_PATH
    (column, path_string [, correlation_integer ])
```

[EXISTS condition](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions012.htm#SQLRF52167)

```
EXISTS (subquery)
```

[Floating-point conditions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions003.htm#SQLRF52113)

```
expr IS [ NOT ] { NAN | INFINITE }
```

[Group comparison conditions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions002.htm#SQLRF52110)

```
{ expr
     { = | != | ^= | <> | > | < | >= | <= }
     { ANY | SOME | ALL }
     ({ expression_list | subquery })
| ( expr [, expr ]... )
  { = | != | ^= | <> }
  { ANY | SOME | ALL }
  ({ expression_list
     [, expression_list ]...
   | subquery
   }
  )
}
```

where `!=`, `^=`, and `<>` test for inequality

[IN condition](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions013.htm#SQLRF52169)

```
{ expr [ NOT ] IN ({ expression_list | subquery })
| ( expr [, expr ]... )
    [ NOT ] IN ({ expression_list [, expression_list ]...
                | subquery
                }
               )
}
```

[IS A SET condition](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions006.htm#SQLRF52129)

```
nested_table IS [ NOT ] A SET
```

[IS ANY condition](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions005.htm#SQLRF52122)

```
[ dimension_column IS ] ANY
```

[IS EMPTY condition](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions006.htm#SQLRF52132)

```
nested_table IS [ NOT ] EMPTY
```

[IS OF type condition](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions014.htm#SQLRF52174)

```
expr IS [ NOT ] OF [ TYPE ]
   ([ ONLY ] [ schema. ] type
      [, [ ONLY ] [ schema. ] type ]...
   )
```

[IS PRESENT condition](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions005.htm#SQLRF52125)

```
cell_reference IS PRESENT
```

[LIKE condition](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions007.htm#SQLRF52142)

```
char1 [ NOT ] { LIKE | LIKEC | LIKE2 | LIKE4 }
  char2 [ ESCAPE esc_char ]
```

[Logical conditions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions004.htm#SQLRF52116)

```
{ NOT | AND | OR }
```

[MEMBER condition](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions006.htm#SQLRF52135)

```
expr [ NOT ] MEMBER [ OF ] nested_table
```

[Null conditions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions008.htm#SQLRF52152)

```
expr IS [ NOT ] NULL
```

[REGEXP\_LIKE condition](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions007.htm#SQLRF00501)

```
REGEXP_LIKE(source_char, pattern
            [, match_param ]
           )
```

[Simple comparison conditions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions002.htm#SQLRF52107)

```
{ expr 
  { = | != | ^= | <> | > | < | >= | <= }
  expr
| (expr [, expr ]...)
  { = | != | ^= | <> }
  ( expression_list | subquery )
}
```

where `!=`, `^=`, and `<>` test for inequality

[SUBMULTISET condition](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions006.htm#SQLRF52138)

```
nested_table1
[ NOT ] SUBMULTISET [ OF ]
nested_table2
```

[UNDER\_PATH condition](https://docs.oracle.com/cd/E11882_01/server.112/e41084/conditions009.htm#SQLRF52159)

```
UNDER_PATH (column [, levels ], path_string
             [, correlation_integer ]
           )
```
