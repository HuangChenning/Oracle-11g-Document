An expression is a combination of one or more values, operators, and SQL functions that evaluate to a value. An expression generally assumes the data type of its components.

Expressions have several forms. The sections that follow show the syntax for each form of expression. Refer to [Chapter 5, "Subclauses"](sqlqr05.md) for the syntax of the subclauses.

See Also:

[Expressions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/expressions.htm#SQLRF004) in [Oracle Database SQL Language Reference](https://docs.oracle.com/cd/E11882_01/server.112/e41084/toc.htm) for detailed information about SQL expressions

[CASE expressions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/expressions004.htm#SQLRF20037)

```
CASE { simple_case_expression
     | searched_case_expression
     }
     [ else_clause ]
     END
```

[Column expressions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/expressions005.htm#SQLRF20043)

A column expression can be a simple expression, compound expression, function expression, or expression list, containing only columns of the subject table, constants, and deterministic functions.

[Compound expressions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/expressions003.htm#SQLRF52070)

```
{ (expr)
| { + | - | PRIOR } expr
| expr { * | / | + | - | || } expr
}

Note: The double vertical bars are part of the syntax
      (indicating concatenation) rather than BNF notation.
```

[CURSOR expressions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/expressions006.htm#SQLRF52077)

```
CURSOR (subquery)
```

[Datetime expressions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/expressions007.htm#SQLRF00401)

```
expr AT
   { LOCAL
   | TIME ZONE { ' [ + | - ] hh:mi'
               | DBTIMEZONE
               | 'time_zone_name'
               | expr
               }
   }
```

[Function expressions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/expressions008.htm#SQLRF52082)

You can use any built-in SQL function or user-defined function as an expression.

[Interval expressions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/expressions009.htm#SQLRF52084)

```
( expr1 - expr2 )
   { DAY [ (leading_field_precision) ] TO
     SECOND [ (fractional_second_precision) ]
   | YEAR [ (leading_field_precision) ] TO
     MONTH
   }
```

[Model expressions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/expressions010.htm#SQLRF52086)

```
{ measure_column [ { condition | expr } [, { condition | expr } ]... ]
| aggregate_function 
     { [ { condition | expr } [, { condition | expr } ]... ]
     | [ single_column_for_loop [, single_column_for_loop ]... ]
     | [ multi_column_for_loop ]
     }
| analytic_function
}
```

Note:

The outside square brackets shown in boldface type are part of the syntax. In this case, they do not represent optionality.

[Object access expressions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/expressions011.htm#SQLRF52088)

```
{ table_alias.column.
| object_table_alias.
| (expr).
}
{ attribute [.attribute ]...
  [.method ([ argument [, argument ]... ]) ]
| method ([ argument [, argument ]... ])
}
```

[Placeholder expressions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/expressions012.htm#SQLRF52091)

```
:host_variable
   [ [ INDICATOR ]
     :indicator_variable
   ]
```

[Scalar subquery expressions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/expressions013.htm#SQLRF52093)

A scalar subquery expression is a subquery that returns exactly one column value from one row.

[Simple expressions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/expressions002.htm#SQLRF52068)

```
{ [ query_name.
  | [schema.]
    { table. | view. | materialized view. }
  ] { column | ROWID }
| ROWNUM
| string
| number
| sequence. { CURRVAL | NEXTVAL }
| NULL
}
```

[Type constructor expressions](https://docs.oracle.com/cd/E11882_01/server.112/e41084/expressions014.htm#SQLRF52094)

```
[ NEW ] [ schema. ]type_name
   ([ expr [, expr ]... ])
```
