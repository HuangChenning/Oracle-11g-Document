This section shows the syntax for the Oracle-supplied data types.

any\_types

```
{ SYS.AnyData | SYS.AnyType | SYS.AnyDataSet }
```

XML\_types

```
{ XMLType | URIType }
```

spatial\_types

```
{ SDO_Geometry | SDO_Topo_Geometry |SDO_GeoRaster }
```

media\_types

```
{ ORDAudio
| ORDImage
| ORDVideo
| ORDDoc
| ORDDicom
| still_image_object_types
}
```

expression\_filter\_type

```
Expression
```
