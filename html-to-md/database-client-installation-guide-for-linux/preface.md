This guide provides instructions about installing and configuring Oracle Database Client on Linux. This guide also talks about installing and configuring database using response files, globalization support, ports, and troubleshooting.

The preface contains the following topics:

## Audience

This guide is intended for anyone responsible for installing Oracle Database Client 11g Release 2 (11.2). Additional installation guides for Oracle Database, Oracle Real Application Clusters, Oracle Clusterware, Oracle Database Examples, and Oracle Enterprise Manager Grid Control are available on the relevant installation media.

See Also:

[Oracle Database Installation Guide](http://www.oracle.com/pls/topic/lookup?ctx=db112&id=GINST) to install Oracle Database using the default settings
