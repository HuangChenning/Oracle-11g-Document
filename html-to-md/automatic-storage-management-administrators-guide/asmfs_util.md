## 13 Oracle ACFS Command-Line Tools

Command-line tools for managing and implementing Oracle Automatic Storage Management Cluster File System (Oracle ACFS), include the following:

- [Basic Steps to Manage Oracle ACFS Systems](asmfs_util001.md)
- [Oracle ACFS Command-line Tools for Linux and UNIX Environments](asmfs_util002.md)
- [Oracle ACFS Command-line Tools for the Solaris Environment](asmfs_util003.md)
- [Oracle ACFS Command-line Tools for the AIX Environment](asmfs_util004.md)
- [Oracle ACFS Command-line Tools for Windows Environments](asmfs_util005.md)
- [Oracle ACFS Command-Line Tools for Tagging](asmfs_util006.md)
- [Oracle ACFS Command-Line Tools for Replication](asmfs_util007.md)
- [Oracle ACFS Command-Line Tools for Security](asmfs_util008.md)
- [Oracle ACFS Command-Line Tools for Encryption](asmfs_util009.md)
- [Oracle ACFS Command-Line Utilities for Multiple Environments](asmfs_util010.md)

Note:

Oracle ACFS encryption, replication, security, and tagging are available starting with Oracle Automatic Storage Management (Oracle ASM) 11g Release 2 (11.2.0.2) on Linux and Oracle ASM 11g Release 2 (11.2.0.3) on Windows.
